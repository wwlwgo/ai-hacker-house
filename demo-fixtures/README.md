# Demo Fixtures

本目录保存工程协同 Agent Relay 的脱敏演示场景。每个场景都必须：

- 使用独立 `trace_id`；
- 使用同一类消息、证据、人工控制和状态字段；
- 明确哪些数据是模拟材料；
- 不包含真实项目、人员、群组、联系方式、文件编号或现场照片；
- 能在 Mock 模式下稳定演示。

当前场景：

| 场景 | 类型 | 状态 |
| --- | --- | --- |
| `sc-pipe-inspection` | 临时、并行专业核查 | P0 主场景 |
| `safety-daily` | 周期、事实合并与多口径输出 | P1 扩展场景 |
